# independent-data-projects
A portfolio of custom Python data pipelines and predictive modeling engines analyzing public infrastructure metrics and athletic performance trends.

# Repository Portfolio
### 1. 'tennis_opponenet_performance_analyzer.py'
A competitive tracking engine that aggregates individual match flight arrays into dynamic dual-match divisional standings, utilizing regex string filtering to isolate high-pressure tiebreakers.
### 2. 'car_crash_analysis.py'
A data pipeline analyzing executing inferential Chi-Square hypothesis testing ('SciPy') and predictive 'RandomForest' classifiers to isolate systemic roadway hazards across New Jersey municipal tiers.
### 3. 'soccer_match_data.py'
A feature-engineered sports analytics framework that normalizes multi-variable tracking metrics to compute custom weighted player impact scores.

# Core Tech Stack
- Languages: Python
- Libraries: Pandas, NumPy, Scikit-Learn, SciPy, Matplotlib
